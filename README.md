# Private Add-on Sync

A Home Assistant add-on that installs add-ons from **private** GitHub
repositories using a personal access token.

## Install

1. Settings → Add-ons → Add-on store → ⋮ → Repositories, add
   `https://github.com/A7QG59F2/ha-private-addon-sync`.
2. Install **Private Add-on Sync**, set `github_token` and `repositories`,
   then start it.
3. Your private add-ons appear under **Local add-ons**.

See [private_addon_sync/DOCS.md](private_addon_sync/DOCS.md) for details.
